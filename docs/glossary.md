## Adding a term

Entries use Markdown definition lists — the term on one line, then a line
starting with `:` and three spaces:

```markdown
Term
:   Definition, ending with a link to the page that covers it.
```

If a term is an abbreviation you want expanded on hover everywhere in the wiki,
add it to `includes/abbreviations.md` instead. See
[Editing This Wiki](contributing.md#abbreviations).
